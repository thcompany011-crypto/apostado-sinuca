# Apostado Sinuca

Sistema simples para controle de partidas de sinuca com aposta.

## Regra
- Até 5 jogadores na fila.
- Os 2 primeiros jogam.
- O vencedor permanece.
- O perdedor sai.
- O próximo da fila entra automaticamente.
- Cada partida é registrada separadamente.
- O valor da aposta pode ser alterado.
- Ranking e histórico são calculados automaticamente.

## Persistência
A primeira versão salva os dados no navegador usando localStorage, permitindo publicação como site estático no GitHub Pages.
